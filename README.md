# CIQ Meetings Dashboard API (OpenAPI)

The OpenAPI 3.0 description of the upload endpoint of the CIQ Meetings Dashboard.

- Spec: [`openapi.json`](openapi.json), published at https://sholl-cisco.github.io/iq-meetings-openapi/openapi.json
- It is a copy of the contract the dashboard serves itself; the service it describes is internal to Cisco and requires an API key.
